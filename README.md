# 📊 주 평균 근무시간 체크

월별 근무시간을 기록하고, 주간/월간 통계를 한눈에 확인할 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 📅 월별 캘린더
- 연/월 선택으로 원하는 달의 캘린더를 확인
- 날짜 클릭으로 근무 기록 입력 폼으로 이동
- 이미 입력된 날짜에는 출퇴근 시간이 표시
- 공휴일 지정/해제 가능 (해당 날짜 재클릭)
- 주말은 자동 비활성화

### ✏️ 근무/휴가 입력
- **일반 근무**: 출퇴근 시간 입력 (기본 휴게시간 1시간 자동 차감)
- **연차**: 8시간 적립
- **반차**: 실제 근무시간 + 4시간 적립 (휴게시간 30분)
- **반반차**: 2시간 적립
- **공휴일**: 8시간 적립
- 메모 기능으로 특이사항 기록 가능

### 📊 월간 통계
- 예상 근무시간 (영업일 × 8시간)
- 현재 적립된 근무시간
- 초과/부족 시간 실시간 표시
- 연차·반차·반반차 사용 현황

### 📈 주간별 통계
- 주간 총 근무시간 및 일 평균 근무시간
- 근무 상태 표시 (정상 / 부족 / 과다)
- 일별 상세 기록 테이블 (유형, 출퇴근, 적립시간, 메모)
- 개별 기록 삭제 기능

### 💾 데이터 저장
- 브라우저 `localStorage`에 자동 저장
- 별도 서버/DB 불필요

## 기술 스택

| 프레임워크 | Next.js (App Router) | 16.1.6 |

## 프로젝트 구조

```
src/
├── app/
│   ├── page.tsx          # 메인 페이지 (캘린더, 상태 관리)
│   ├── layout.tsx        # 루트 레이아웃
│   └── globals.css       # 글로벌 스타일
├── components/
│   ├── index.ts          # 컴포넌트 배럴 파일
│   ├── WorkEntryForm.tsx # 근무/휴가 입력 폼
│   ├── WorkEntryList.tsx # 주간 요약 + 상세 기록 테이블
│   └── MonthlyOverview.tsx # 월간 통계 대시보드
├── types/
│   └── index.ts          # 타입 정의 (WorkEntry, MonthlyStats 등)
└── utils/
    └── calculate.ts      # 근무시간 계산, 주간 그룹핑, 포맷 유틸
```

## 시작하기

### 사전 요구사항

- Node.js 18 이상
- npm (또는 yarn, pnpm)

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

[http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

### 빌드

```bash
# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start
```

### 린트

```bash
npm run lint
```

## 근무시간 계산 규칙

| 항목 | 규칙 |
|------|------|
| 영업일 기준 | 월~금 (주말 자동 제외) |
| 월 예상 근무시간 | 영업일 수 × 8시간 |
| 미입력 평일 | 8시간으로 간주하여 부족/초과 예상치 계산 |
| 일반 근무 | (퇴근시간 - 출근시간) - 휴게시간(1시간) |
| 연차 | 8시간 적립 |
| 반차 | 실제 근무시간 + 4시간 |
| 반반차 | 2시간 적립 |
| 공휴일 | 8시간 적립 |
